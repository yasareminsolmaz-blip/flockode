## English (primary)

**Subtitle** (30 karakter): `One code for the whole flock`

**Promotional text**
> Write one program and watch every sheep run it at once. A coding puzzle where your code has to work from every square, not just by luck.

**Description**
> Flockode is a coding puzzle for kids aged 8–12 with a twist: you write one program, and every sheep in the flock runs it at the same time.
>
> The sheep start in different places and face different ways, so a memorized route won't work. Kids build IF → THEN rules ("IF there is a fence ahead, turn right") and discover how to write code that is truly general.
>
> • One code, many sheep: real programming thinking, not step-by-step steering
> • Shuffle the flock and test every square to see if your code is right or just lucky
> • Spot endless loops: sheep that go round in circles are marked with a question mark
> • Rule order matters, just like in real code
> • 20 worlds and 200 levels: fences, flowers as signs, side steps, wolves and streams
> • Three stars per level: flock home, works from every square, shortest code
> • Hints that reveal the solution one line at a time
> • Six languages: English, Turkish, German, Spanish, Dutch and French
>
> Worlds 1–2 (20 levels) are free. A single one-time purchase unlocks worlds 3–20.
>
> Safe for kids: no ads, no accounts, no data collection and no internet needed. Purchases and the App Store link are behind a parental gate.

> Flockode needs no account and no network. Worlds 1–2 are free; worlds 3–20 unlock with the non-consumable in-app purchase com.yasarss.flockode.full. Buying, restoring and the App Store link to our other game (Robo Rota) are behind a parental gate that asks a multiplication question (for example 7 × 8 = 56). The game collects no data and contains no ads or analytics.
